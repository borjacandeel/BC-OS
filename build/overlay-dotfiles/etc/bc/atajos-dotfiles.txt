ATAJOS DEL ENTORNO «DOTFILES» (bspwm)  —  Súper = tecla Windows (⌘). Todos van con Súper, como en BC OS

Aplicaciones
  Súper+Intro                Terminal              Súper+Espacio / Súper+D  Lanzador (rofi)
  Súper+B                    Firefox               Súper+E                  Archivos (pcmanfm)
  Súper+Tab                  Cambiar de ventana    Súper+X                  Menú de energía
  Ctrl+Súper+Q               Bloquear              Súper+F1                 Esta lista

Ventanas
  Súper+W / Súper+Q          Cerrar (Súper+Mayús+W: forzar)
                Súper+T / Mayús+T / S / F  Mosaico / pseudo / flotante / pantalla completa
  Súper+H J K L              Foco (con Mayús: intercambiar)
  Súper+flechas              Cambiar de ventana por dirección (con Mayús: intercambiar)
  Súper+M                    Mosaico ↔ monóculo    Súper+G                  Intercambiar con la mayor
  Súper+1…0 (Alt: enviar)    Escritorios           Súper+[ / ]              Escritorio anterior / siguiente
  Súper+Alt+H J K L          Redimensionar (con Mayús: contraer)
  Súper+Ctrl+H J K L / 1…9   Preselección de dirección / de proporción
  Súper+Alt+flechas          Mover una ventana flotante
  Súper+arrastrar            Mover (botón izq.) · redimensionar (botón der.)

Capturas
  Súper+Mayús+3 / 4          Pantalla / zona (con Ctrl: solo al portapapeles)

Sesión
  Súper+Mayús+R              Recargar bspwm        Súper+Escape             Recargar los atajos
  Súper+Alt+Q                Salir de bspwm

Capturas y fondos
  Impr                       Pantalla completa     Súper+Mayús+S            Área al portapapeles     Alt+Impr  Ventana
  Súper+N / Mayús+N / Alt+N  Fondo siguiente / anterior / aleatorio

Personaliza en ~/.config/{bspwm,sxhkd,polybar,picom,rofi,dunst,alacritty}. «bc-dotfiles-setup --reset» restaura los originales.
